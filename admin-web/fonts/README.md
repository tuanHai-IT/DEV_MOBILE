# Font cho EcoShare Admin

Font được phục vụ từ project để giao diện không cần tải font từ dịch vụ bên ngoài.

- Be Vietnam Pro: Regular (400), Medium (500), SemiBold (600), Bold (700). Nguồn: [Google Fonts — Be Vietnam Pro](https://github.com/google/fonts/tree/main/ofl/bevietnampro). Giấy phép: `OFL.txt`.
- Playfair Display: variable weight. Nguồn: [Google Fonts — Playfair Display](https://github.com/google/fonts/tree/main/ofl/playfairdisplay). Giấy phép: `PlayfairDisplay-OFL.txt`.

Các tệp font gốc không bị chỉnh sửa.
