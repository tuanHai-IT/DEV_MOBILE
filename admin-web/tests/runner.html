Kiểm tra kết nối Firebase

Ba bài kiểm tra Firebase cần Emulator và dữ liệu seed trên project demo-recycling-share. Các bài kiểm tra giao diện còn lại dùng API giả lập trong trình duyệt và không ghi Firebase.

  • Đăng nhập, phân quyền và quản trị cơ bản
  • Bài chia sẻ, bình luận và quản trị nội dung
  • Tạo, đọc và sửa Cấu hình
  • Nút xóa bài chia sẻ, mẹo hay và tin bán
  • Cập nhật dữ liệu tức thì
  • Điều hướng 16 mục Admin và menu Moderator
